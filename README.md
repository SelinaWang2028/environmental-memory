> History is also what people remember breathing, losing, crossing and rebuilding.

**Environmental Memory** is an open, community-led oral-history archive that
documents how people live through industrial transformation, pollution,
ecological recovery, heritage conservation, relocation, and the long afterlife
of conflict. Most environmental history is written from policy documents and
statistics; we start from the workshop floor, the village lane, the tea garden,
and the minefield — in people's own words.

## Quick start

No build step and no server are needed.

- **View it:** download the repository and open `index.html` in any browser.
- **Live:** it is fully static, so hosting it is just serving the files.
- The page loads [ECharts](https://echarts.apache.org/) and the web fonts from a
  CDN; everything else (including all images) is local. To use it fully offline,
  download those assets too.

## Contributing

There are many ways to help: transcribe or translate, add a field site, improve
accessibility, or contribute a photograph. Please read
[CONTRIBUTING.md](CONTRIBUTING.md), the [code of conduct](CODE_OF_CONDUCT.md),
and the [ethics notes](docs/ethics.md) before collecting oral history.
