# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-20

First public, open-source release.

### Added
- Four deep field sites: Jincheng/Yangcheng, Tianshanzhuang (Shanghai),
  Wuyishan National Park, and Angkor/Siem Reap; Shougang listed as in development.
- Field-site overview and an interactive world map.
- Oral-history voice cards in the narrator's own language with translations.
- A range of figures: heatmap, grouped and stacked bars, signed bars, lines,
  and a horizontal monitoring network.
- Machine-readable metadata in `data/`.
- Open-source project files: MIT licence, CC BY 4.0 content licence,
  contributor docs, consent form, and ethics notes.

### Notes
- Some illustrative images are sourced from web search and are flagged
  "TO REPLACE" in `ATTRIBUTIONS.md` pending confirmed licences.
- Charted indices are researcher-coded summaries from interviews, not official
  statistics.
